# Smart Recruitment & ATS

Qveto Technologies Web Development Project 1

## About

Web app to manage hiring in one place: job posts, applications, interviews, offers, and onboarding. Admin, HR, and Candidate have separate dashboards, and access is enforced on the server.

## Features

- Role-based dashboards (Admin, HR, Candidate)
- Job posting and online applications
- Pipeline: Applied → Screening → Interview → Selected → Offered
- Interview scheduling and email notifications
- Offer letter generation
- Hiring analytics

## Tech Stack

- Frontend: React, HTML, CSS, JavaScript/TypeScript
- Backend: Node.js, Express
- Database: PostgreSQL
- Tests: unit, API, and browser E2E (planned)
